# 智能视觉系统用户操作指南

## 一、系统启动
系统上电后自动启动，无需手动操作。等待30秒后，即可访问。

## 二、访问方式
| 功能 | 地址 |
|:---|:---|
| 终端控制界面 | http://树莓派IP:5000/ |
| 管理后台 | http://树莓派IP:5000/dashboard |

## 三、终端控制界面操作
### 3.1 查看实时视频
打开页面后，视频区域显示摄像头实时画面。

### 3.2 启动/停止检测
- 点击"▶ 启动"按钮：开始检测
- 点击"⏸ 停止"按钮：停止检测

### 3.3 手动操作
- 点击"📷 拍照"按钮：保存当前画面并检测

### 3.4 查看状态
页面底部显示FPS、帧数、运行时间。

## 四、管理后台操作
### 4.1 查看统计数据
页面顶部显示总检测数、今日检测、各类别占比。

### 4.2 查看图表
- 饼图：显示各类别分布
- 柱状图：显示各类别数量对比

### 4.3 查看历史记录
页面中部显示历史检测记录，点击"刷新"可更新。

### 4.4 修改设置
在设置区域修改参数，点击"保存设置"。

## 五、常见问题
| 问题 | 解决方法 |
|:---|:---|
| 页面无法访问 | 检查树莓派是否开机，服务是否运行 |
| 视频流不显示 | 刷新页面，检查摄像头连接 |
| 数据不更新 | 检查检测是否启动 |
