## 二、系统基础环境
### 2.1 烧录系统
1. 使用 Raspberry Pi Imager 烧录 Raspberry Pi OS Bookworm 64位系统
2. 烧录前配置 Wi-Fi、SSH、用户名密码，启用摄像头接口
3. 首次开机完成系统初始化，确保网络连通
